# まわりマップ

住所や地名から周辺位置へすばやく移動し、半径を重ねて生活圏を可視化する静的ウェブアプリです。
引っ越し検討、徒歩圏の確認、ざっくりした商圏チェックなどを想定しています。

## 機能
- **半径メモ**: 地図上の好きな場所をタップし、半径円を複数重ねて表示できます。
- **現在地検索**: ワンクリックで現在地に移動し、周辺範囲を確認できます。
- **行政区画表示**: 住所検索時、その市区町村の境界線を自動で表示します。
- **美しいUI**: 直感的でモダンなデザイン（レスポンシブ対応）。

## 使用技術
- **HTML/CSS/JavaScript**: フレームワークなしの軽量設計
- **Leaflet.js**: 地図表示ライブラリ
- **Geolonia**: 住所データおよび行政区画GeoJSON
- **国土地理院**: 背景地図タイル

## データ出典
このアプリは以下のオープンデータを使用しています。
- [国土地理院 地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)
- [Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)
- [Geolonia 行政区画データ](https://github.com/geolonia/japanese-admins)

## デプロイ方法 (Render)
1. このリポジトリをGitHubにプッシュします。
2. Render.comのアカウントを作成・ログインします。
3. "New + " -> "Static Site" を選択します。
4. GitHubリポジトリを連携・選択します。
5. 設定はそのままで "Create Static Site" をクリックすれば完了です。
