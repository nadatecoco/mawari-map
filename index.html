まわりマップ BETA
オープンデータで住所周辺へ移動し、半径メモを地図上に重ねられます。
プライバシー GitHub

ガイド

  1. 住所・駅名・地名を入力して「移動」
  2. 候補が複数あれば一覧から選択
  3. PCはダブルクリック、スマホはタップで円を追加
  4. ポップアップで半径や色を調整

引っ越し検討、徒歩圏の把握、商圏のラフ確認などを想定した軽量ツールです。

このサイトについて

まわりマップは、住所や地名から周辺位置へすばやく移動し、地図上に半径を重ねて「生活圏」や「届く範囲」を見やすくするためのシンプルな地図ツールです。

背景地図や住所データにはオープンデータを利用し、できるだけ低コストで継続公開できる構成を目指しています。

利用方針

  • 本サイトは目安確認用です。正確な測量や法的判断には使わないでください。
  • 検索・地図表示には外部の公開データと配信サービスを利用しています。
  • 位置情報を使う機能は、ブラウザの許可がある場合のみ動作します。
  • 広告や運営告知を掲載する場合があります。

データ出典: 国土地理院タイル / Geolonia 住所データ・行政区画データ

候補から選択

候補が多い場合は入力を少し詳しくしてください。
